# Работа с рефами: методика и реестр приёмов

## Методика

1. **Реф = направление, не шаблон.** НИКОГДА не копировать реф 1:1.
   Из каждого рефа выписываются принципы/приёмы, и моделируется СВОЙ
   вариант под наши данные и нашу тему «Старинный свиток»
   (konoha_theme.py — палитра/шрифты, live.py — токены self.colors).
2. Прежде чем писать код: письменно зафиксировать список приёмов,
   которые берём из рефа (и что сознательно не берём).
3. Совместимость: новый приём обязан дружить с текущей палитрой и
   типографикой; контраст и читаемость данных ВАЖНЕЕ декора.
4. Один приём за один шаг: минимальный дифф → py_compile → смоук-скрин
   → пиксельная проба → визуальная сверка с рефом.
5. Новые рефы докидывает Эдди в ..\рефы\; после разбора файл добавляется
   в реестр ниже (имя файла → извлечённые приёмы), чтобы не пересматривать.
6. Vision-гигиена: после смены модели проверять зрение контрольной
   картинкой с известным содержанием (нарисовать PIL-картинку, прочитать,
   описать ТОЧНО). Транспортное «Image read successfully» без восприятия =
   нет зрения; тогда только пиксельные пробы + глаза Эдди.

## Реестр разобранных рефов (приёмы)

### kartamiranaruto.jpg — карта мира Наруто (пергамент)
Берём: сильную виньетку затемнения краёв; затенение побережий суши;
красные кольца-маркеры ключевых локаций + легенду внизу слева;
декор на воде (кораблики); крупные стилизованные надписи районов прямо
на карте; водяной знак символа деревни на пустой части суши.
Не берём: фэнтезийную топографию (у нас свои данные мира).

### artiste-graphiste-hud-naruto-1.jpg — HUD-свиток со шкалами
Берём: градиентные вертикальные стат-бары; «рваные» рамки-мазки кистью
вместо чистых прямоугольников; рукописные пиктограммы под шкалами
(рамэн=нужды, сердце=эмоции, ладони=доверие...); вертикальную плашку
с названием; сюрикен как угловой орнамент.
Не берём: конкретных персонажей/имён (KIBA INUZUKA).

### a0611b152747219.63478e76c6289.png — постер-типографика (шаринган)
Берём: круговую типографику текста вокруг центрального символа;
жирный дисплейный шрифт для крупных заголовков; плотный микро-текст
как фактуру (стиль ленты событий); ч/б палитру + один акцент;
индексные счётчики вида [010/010] для прогресса прогона/тиков.
Не берём: контент про клан Учиха (у нас свой агент).

### Wind-Main-Basic-Lineup.png — боевой экран фан-игры
Берём: плашки-мазки кистью под заголовками; круглые светящиеся ячейки
для позиций (идея для метрик/аватаров); правую панель-список
«сущность + значение + счётчик»; нижнюю панель действий как единый
командный бар; угловые орнаменты внешних рамок.
Не берём: боевую механику и персонажей.
