## ЧТО ПРОВЕРИТЬ

1. Карта подсистем: core\ (Agent, роутинг, познание, клеймы,
   автономия), identity\ (цели/черты/эмоции/привычки/рефлексия),
   memory\ (SQLite events/knowledge/evidence).
2. Путь сигнала: Agent.respond(str) -> str: полный маршрут обработки,
   точки падения без обработки исключений, блокировки/глобальное
   состояние, потокобезопасность.
3. Конвейер личности evidence -> proposal -> lifecycle: целостен ли,
   нет ли обходных путей мимо него.
4. Память: схема SQLite (events/knowledge/evidence), индексы,
   потенциальный бесконечный рост, миграции.
5. Кодировки: файлы с литеральными «?» вместо кириллицы (файл ->
   число вхождений); признаки двойного перекодирования («Ð», «Ñ»).
6. Мёртвые импорты/код, дубли функциональности между core и identity.
7. Готовность к мосту с миром (simulation eddie/bridge.py вызывает
   respond(str) и берёт снимок состояния): какие интерфейсы должен
   дать агент, чего не хватает, хрупкие места.
8. Риски для полного прогона с LLM сегодня ночью (что может упасть).
