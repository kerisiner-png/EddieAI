## ТОП-проблем проекта (по всем этажам, с приоритетом)

### Критично (влияет на текущий функционал/честность состояния)
1. **Этаж 4: EvidenceConsolidator.consolidate() в автономном тике — мёртвый хук.** Кандидаты собираются, но не применяются (`autonomous_runtime.py:632-661`). Автономное накопление evidence не работает.
2. **Этаж 4/7: ReflectionEngine.reflect() возвращает signals, но они нигде не потребляются** (`agent_loop.py:1084-1098`) — автономная рефлексия не копит личностные evidence.
3. **Этаж 7: сны не пишут событий в проде** (`snapshots_enabled=False` по умолчанию) — провенанс DREAM и артефакты рубежа A де-факто живут только при явной ночи/включении.
4. **Этаж 9: любопытство исполняется, только если `enable_decision_core=True`.** В конфигурации без DecisionCore цель-кандидат CuriosityDirector никогда не активируется (`goal_generator` работает только с motivation-кандидатами). Night_run использует True — в проде работает, но «живой орган» хрупок к конфигурации.

### Важно (мусор/долги/честность деклараций)
5. **19 `*.backup` + `agent_py_recovery_2026-08-24\`** в живых папках — не входят в код, но засоряют дерево и grep.
6. **`identity/user.py` — мёртвый** (импортируется только из recovery-снапшотов).
7. **Мёртвая таблица `evidence` (БД)** поверх живой `evidence_events` (`database.py:118`).
8. **Этаж 8: «CPU» и «топ-процессы» заявлены, но не реализованы** в `world_probe.py` (только RAM/диск; `_meminfo()["load"]` — загрузка RAM, не CPU).
9. **Этаж 10: двойная STT-архитектура** (voice_io.py: whisper основной + Vosk детектор; voice_repl.py — наоборот) + ROADMAP неверно описывает voice_repl (не поднимает автономию).
10. **Этаж 14: long-term memory / semantic retrieval / knowledge graph — пусто** (SQLite + LIKE, без embeddings/вектора/графа). **Стоимость облачного роутинга не учитывается**, max_tokens зажат.

### Низкий приоритет (бэклоги, уже известны)
11. Три разрозненных промо-механизма (PromotionEngine 0.80 / EvidenceConsolidator 0.70 / PersonalityEngine 0.75) без единого узла.
12. `data/`: `diary.db` И `personal_diary.db` — два дневника, живой требует уточнения.
13. `test_auto_call`/`test_call_interrupt` сломаны на импорте; `test_goal_generation.py` print-only без assert'ов.
14. Слабые места: `test_production_runtime` не покрывает любопытство; `test_world_trigger` не бьёт по вызову из tick при критической RAM.
15. Значительный слой «квитов-зародышей» на этаже 4/5: конвейер evidence→proposal→promotion применён точечно, не как система.
