# Роутинг моделей: big-pickle ↔ Ox Alpha Free ↔ Mistral

[АКТУАЛЬНО] Утверждено Эдди 22.08.2026. Правила обязательны для всех
сессий opencode в этом проекте. Факты о моделях — разделы 7–8.

## 1. Роли моделей

- **big-pickle** (`opencode/big-pickle`) — ОСНОВНАЯ модель проекта:
  стабильный провайдер (22.08 — полный рабочий день без единого сбоя),
  полноценная агентная работа с кодом. Зрения НЕТ (чтение изображений
  возвращает «does not support image input»).
- **x-preview-f-free** (`opencode/x-preview-f-free`, Ox Alpha Free) —
  ЗРЕНИЕ + РЕЗЕРВ: видит скриншоты и рефы; zero-retention провайдер;
  первая запасная рабочая модель, если big-pickle вдруг недоступен.
  Нестабильна: в часы нагрузки 503 по 3–6 ретраев на запрос
  (потери — минуты на каждый вызов инструмента).
- **mistral/codestral-latest, mistral/devstral-latest,
  mistral/mistral-small-latest** (провайдер Mistral La Plateforme,
  ключ уже в auth.json) — ВНЕШНИЙ РЕЗЕРВ ВНЕ ZEN: работает из РФ без
  VPN, ответы 0.4–2 с, русский текст чистый. Бесплатный tier со
  СВОИМИ лимитами, отдельными от квоты Zen. Зрение НЕ проверено
  (при первом использовании — контрольный PIL-тест).

## 2. Принцип

Модель выбирает ЗАДАЧА, а не привычка. Базовое состояние любой
сессии — big-pickle. Ox Alpha включается короткими чекпоинтами строго
под зрительные задачи; все чтения картинок — одной пачкой за заход.
Отдельная роль Ox Alpha — резерв: при недоступности big-pickle она
берёт на себя обычную работу (код/диагностика), насколько позволяет
стабильность провайдера.

## 4. Протокол смены (честная автоматизация)

ВАЖНО: агент сам свою модель сменить НЕ МОЖЕТ — переключает Эдди
командой /models. Автоматизация = мгновенные триггеры агента +
одно действие Эдди без обсуждений.

Вперёд (понадобилось зрение):

1. Агент печатает маркер:
   `>>> СМЕНА МОДЕЛИ -> Ox Alpha Free | причина: ... | пачка: N файлов`
2. Эдди переключает модель, отвечает «готово».
3. Агент ОБЯЗАТЕЛЬНО проводит контрольный PIL-тест зрения
   (рисует картинку с известным содержимым и читает её; урок
   22.08 в MEMORY.md). Без PASS описания картинок не выдаются.
4. Агент читает ВСЕ файлы пачки, сразу фиксирует наблюдения словами
   (в ответе или отдельном файле), закрывает чекпоинт отчётом.

Назад (чекпоинт закрыт):

5. Агент печатает маркер:
   `>>> СМЕНА МОДЕЛИ -> Big Pickle | чекпоинт закрыт`

## 5. Правила экономии переключений

- Одиночные «глянуть одну картинку» запрещены — копим до пачки.
  Исключение: чтение блокирует текущую работу прямо сейчас.
- Смешанная задача (код + посмотреть): весь код на big-pickle,
  визуальная часть — в конец сессии одной пачкой.
- Перед чекпоинтом агент готовит точный список файлов к просмотру.

## 6. Аварийные правила

- Ox Alpha даёт более 2 подряд неудачных/подвисших запроса =>
  чекпоинт ПРЕРЫВАЕТСЯ; остаток визуальной работы переносится на
  следующий заход либо заменяется пиксельными пробами; возврат на
  big-pickle.
- big-pickle недоступен/упёрся в лимиты =>
  1) ПЕРВЫЙ резерв — Mistral (`mistral/devstral-latest` для кода,
     `mistral/codestral-latest`, `mistral/mistral-small-latest`):
     работает из РФ без VPN, лимиты отдельные от Zen; зрение НЕ
     проверено (при первом запуске контрольный PIL-тест).
  2) ВТОРОЙ резерв — Ox Alpha Free: обычная работа (код/диагностика/
     документация); помнить про нестабильность провайдера; зрительные
     задачи при этом можно делать сразу, без смены модели.
- Бесплатный пул Zen — ОДНА квота на аккаунт (23.08: одновременные
  429 от big-pickle, mimo-v2.5-free, hy3-free за один прогон).
  Ротация между бесплатными моделями Zen при исчерпании лимита
  БЕССМЫСЛЕННА — уходить в Mistral. Параллельные сессии делят ту же
  квоту: одна может выжечь лимит другой («в этой сессии работает,
  в той нет»).
- Гео-блок РФ (403, проверено 23.08): OpenRouter, Groq, Cerebras,
  NVIDIA Nemotron endpoints (в т.ч. через Zen); z.ai — timeout.
  Без VPN не пытаться.
- После ЛЮБОЙ смены модели первое действие агента — контрольный тест:
  идентичность («какая ты модель») + зрение (при переходе на Ox Alpha).
