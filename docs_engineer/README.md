## Главные правила

1. **ВСЁ всегда на русском** — общение, документы, комментарии в коде,
   и внутреннее проговаривание агента (thinking) тоже на русском.
2. **Разделение статусов.** Каждый файл делится на две зоны:
   - `[АКТУАЛЬНО]` — верх файла, действует прямо сейчас;
   - `[АРХИВ]` — нижняя зона, история. НЕ удалять никогда.
   Запись, теряя силу, переносится в архив с датой и пометкой
   почему (`[АРХИВ 22.08] закрыто: ...`).
3. **Сверяйся с файлами, а не с памятью.** Перед работой прочитать
   PROJECT_STATE.md + COORDINATION.md + TODO.md. Факт считается фактом,
   только если он в файле или проверен прямо сейчас.
4. **Документируй всё.** Правка кода → запись в CHANGELOG. Ошибка →
   MEMORY. Догадка → ASSUMPTIONS. Новая задача → TODO. Нет записи —
   считай, что работы не было.
5. **Кодировки:** все файлы UTF-8 строго без BOM. Исходники не править
   через Set-Content/Out-File/Add-Content (пишут cp1251/BOM).
6. **Времена** в записях — только артефактные (mtime, логи, StartTime
   процессов). Никогда «по ощущениям».
7. **Маркировка достоверности** (наследие AGENTS.md):
   `[Подтверждено]`, `[Вероятно]`, `[Неизвестно]`.
8. **Append-only для журналов**: CHANGELOG и MEMORY пополняются,
   существующее не переписывается задним числом.
9. **Один пишущий исполнитель** за раз; читающие суб-агенты можно.
10. Итоговые отчёты смен — в `C:\EddieAI_Simulations\отчеты\`.

## Формат записи (единый)

```
### [АКТУАЛЬНО|АРХИВ ГГГГ.ММ.ДД] Краткий заголовок
Детали: что/где/почему.
Проверка: как подтверждено (артефакт).
```

## Цикл закрытия задачи

работа → проверка (тест/байт-проверка) → CHANGELOG → TODO (статус) →
если ошибка: MEMORY → если догадка: ASSUMPTIONS → отчёт пользователю.
