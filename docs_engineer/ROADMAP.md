# Роудмап EddieAI — генеральный и сменный

[АКТУАЛЬНО] Генеральный роудмап утверждён пользователем (совет
директоров). Менять формулировки этажей нельзя без его решения.

## Цель проекта

Создать EddieAI — цифровую личность с собственной памятью, характером,
мотивацией и внутренней жизнью, которая растёт этаж за этажом — от
ядра к саморазвитию. Жить он будет сначала у Эдди на его ПК, позже —
в свободном интернете. Симуляционный мир — НЕ дом и НЕ цель: это
инструмент, испытательный полигон среды. [Формулировка исправлена по
поправке Эдди 22.08; менять только через него]
