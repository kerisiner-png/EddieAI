## III. Что нужно цифровой личности (EddieAI)

Ключевые потребности:
1. **Живой русский язык** — не переведенный, а естественный; модели должны хорошо знать русскую культуру, идиомы, сленг
2. **Эмоциональная выразительность** — способность передавать чувства через текст (не шаблонные ответы)
3. **Контекстуальная память** — удержание личности и предыдущих разговоров в контексте
4. **Автономное исследование** — поиск информации, формулирование вопросов, анализ
5. **Рефлексия** — осмысление своего опыта, самокритика, рост
6. **Генерация планов и целей** — долгосрочное планирование, декомпозиция задач

## IV. Ранжированная рекомендация — ТОП-3

### 🥇 1. Qwen3.5-plus (PRIMARY — основной "голос" личности)

**Почему именно он:**
- **Лучшее соотношение цена/качество** на рынке: ¥0.8/¥4.8 (~$0.11/~$0.66 за 1M) — в 10-15 раз дешевле топовых моделей
- **1M контекст** — позволяет удерживать огромную историю личности, память, характер
- **Отличный русский язык** — Qwen серия специально обучена на massive multilingual данных, русский входит в топ-5 поддерживаемых языков
- **Хорошая креативность** — через system prompt можно задать характер, эмоции, стиль общения
- **Thinking mode** — для рефлексии и глубоких размышлений можно включить thinking
- **Практически бесплатный** для ежедневного использования

**Роль в системе:** Основной разговорный модуль — "голос" Эдди. Все диалоги, эмоции, personality — через него.

**Цена:** ~$0.11 input + ~$0.66 output за 1M tokens. При 10K tokens/день = **~$0.008/день** (менее 1 цента).

---

### 🥈 2. DeepSeek V4 Flash (RESEARCH — исследовательский модуль)

**Почему именно он:**
- **$0.22/$0.66** — очень дешёвый, быстрый
- **1M контекст** — можно загружать целые документы для анализа
- **Thinking mode** — глубокий анализ и рассуждения
- **Отличный для автономного исследования** — поиск информации, анализ, формулирование выводов
- **Сильная логика** — подходит для генерации планов и декомпозиции задач
- **API совместимость** — легко интегрируется (OpenAI + Anthropic формат)

**Роль в системе:** Исследовательский модуль — "интеллект" личности. Анализирует информацию, формулирует вопросы, строит планы, делает выводы.

**Цена:** ~$0.22 input + ~$0.66 output за 1M tokens. При 5K tokens/день = **~$0.004/день**.

---

### 🥉 3. Qwen3.7-plus (DEEP-THOUGHT — модуль глубокой рефлексии)

**Почему именно он:**
- **¥2/¥8 (~$0.28/~$1.10)** — дороже flash-моделей, но значительно дешевле max
- **Thinking mode по умолчанию** — идеален для рефлексии и глубоких размышлений
- **1M контекст** — полная история жизни личности
- **Более качественные рассуждения** чем V4 Flash — лучше для самокритики, анализа эмоций, философских размышлений
- **Batch调用 (50% скидка)** — ещё дешевле для фоновых задач

**Роль в системе:** Модуль глубокой рефлексии — "сознание" личности. Используется для: ночных рефлексий, анализа эмоционального состояния, генерации долгосрочных целей, самокритики.

**Цена:** ~$0.28 input + ~$1.10 output за 1M tokens. При 2K tokens/день = **~$0.003/день**.
