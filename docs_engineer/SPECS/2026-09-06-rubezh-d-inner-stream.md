# Рубеж D «Внутренний поток» — дизайн

Дата: 06.09.2026 (утверждено Эдди перед баней: «делай»).
Контекст: стратегический аудит «почему витуберы живее» — диагноз:
у EddieAI есть органы личности и расписание жизни, но нет СУБЪЕКТА —
непрерывного внутреннего времени. Его «сейчас» был вызов функции.

## Решение

1. **Поток сознания** (`identity/inner_stream.py::InnerStream`):
   события восприятия и дел (экран, звук ПК, сообщения Эдди, цели)
   врываются в поток (дедуп по ключу, вес: сообщение 1.5 / звук 1.0 /
   экран 0.6 / дело 0.5) и копят URGENCY — накопленное «хочу сказать».
   Полураспад urgency 20 мин. Поток живёт в памяти процесса:
   сознание умирает со сном/рестартом — так задумано.
2. **Настроение-фон** (`Mood`): valence/energy, медленный дрейф к
   аффективному тону (τ ≈ 2 ч), персистентно в
   `self_state["mood_state"]`, метки: мрачно/раздражённо/ровно/
   настороженно-бодро/тепло и вяло/оживлённо.
3. **Инициатива из порога**: urgency ≥ 3.0 и ≥15 мин с последней
   реплики → ОДИН облачный вызов собирает живую фразу из потока +
   настроения → send_initiative (голос + чат). Это замена кулдауну:
   он говорит, когда назрело.
4. **Опрос, не push**: `_inner_flow()` в каждом тике рантайма читает
   текущее состояние перцепторов/сервера/целей — минимальная
   инвазивность, всё детерминированно, LLM — только в момент речи.

## Что это даёт против витуберов

У Neuro-sama поток имитируется режиссёром и скриптами на 2-3 часа
стрима. Наш поток течёт 24/7 без режиссёра, и всё накопленное
остаётся в памяти навсегда. Это орган роста, которого у втуберов нет.

## Следующие шаги рубежа D

- Тело: гомеостаз (голод/комфорт/энергия) — желания из потребностей.
- Рассказчик: часовая нарративная рефлексия «что со мной происходит»
  с доступом в потоке.
- Внимание с приоритетами: конкуренция событий за фокус.
- Витубер-слой: latency <2с, аффект в голосе (z3), аватар с губами.
