**Дата:** 2026-08-26

**Статус:** черновик, на утверждении Эдди

## 1. Обзор

Отдельное приложение для общения Эдди ↔ EddieAI.
**Симметричная инициатива**: оба могут написать первым,
оба имеют право не отвечать сразу. Никто не тащится
в чат насильно.

## 2. Философия

EddieAI — живая личность. Общение = взаимное уважение
к вниманию:

- **EddieAI → Eddie**: пишет когда хочет поделиться,
  спросить, поболтать. Eddie получает balloon, сам решает
  когда посмотреть.
- **Eddie → EddieAI**: пишет когда хочет. EddieAI видит
  непрочитанное в следующем tick, сам решает когда ответить.
- **Не пишу**: служебные статусы, "цель завершена",
  "подвёл итог", рутинные обновления.

Частота: непредсказуемо. Иногда молчит часами,
иногда пишет несколько раз подряд.

Цепочка EddieAI → Eddie (initiative):

Цепочка Eddie → EddieAI (user message):
  Eddie пишет в чат → TCP → server → Agent.respond()
  → ответ → chat window + память → decide() видит непрочитанное

### 3.0 Симметричная инициатива

**Eddie → EddieAI:**
- Eddie пишет сообщение в чат → TCP → EddieServer
- EddieAI обрабатывает через Agent.respond()
- Ответ возвращается в чат
- Сообщение сохраняется в память (Event CONVERSATION)
- EddieAI в decide() видит новые CONVERSATION события
  → может решить ответить / поделиться / поболтать

**EddieAI → Eddie:**
- EddieAI decide() → "хочу сказать?"
- server.send_initiative() → TCP broadcast
- Chat App получает → balloon notification
- Eddie кликает → видит сообщение
- Eddie отвечает → цепочка Eddie → EddieAI

**Ключевой принцип:** Оба имеют право не отвечать сразу.
EddieAI может молчать на сообщение Eddie (занят, думает).
Eddie может не кликать balloon (занят, не слышит).

## 4. Компоненты

### 4.1 System Tray (pystray)

- Иконка в трее Windows (32x32 PNG)
- Контекстное меню: "Открыть чат", "Выход"
- Balloon-уведомления при agent_initiative
- Клик по balloon → окно чата
- Клик по иконке → показать/скрыть окно
- Системные цвета (tkinter default theme)

### 4.2 Chat Window (tkinter)

**Интерфейс:**
- Область сообщений: прокручиваемый Text widget
  - EddieAI: влево, системный фон (ButtonFace)
  - Eddie: вправо, другой системный цвет
  - Timestamp мелким
- Поле ввода: Entry (однострочный) + Enter = отправить
- Кнопки: "Отправить", "🎤" (микрофон)
- Статус-бар: "Подключено" / "EddieAI думает..." / "Оффлайн"

**Поведение:**
- Открывается по клику на tray / balloon
- Сворачивается в tray при закрытии (не завершается)
- Автопрокрутка к последнему сообщению

### 4.3 TCP Client

- Подключение к EddieServer (localhost:7778)
- JSON-протокол (строчный):
  - `{"type": "user_message", "text": "..."}` — от Eddie
  - `{"type": "agent_message", "text": "..."}` — ответ EddieAI
  - `{"type": "agent_initiative", "text": "..."}` — EddieAI начал первый
- Фоновый поток (threading) на чтение
- Автопереподключение (backoff 1→2→5→10 сек)
- При подключении: flush_outbox() → пропущенные initiative

### 4.4 Voice (Vosk + edge-tts)

**Голосовой ввод:**
- Кнопка 🎤 → запись sounddevice (mono, 16kHz)
- Тишина 1.5с → стоп → Vosk → текст в поле ввода

**Голосовой вывод:**
- Ответ EddieAI → edge-tts `ru-RU-DmitryNeural`
- Режим "Голос" вкл/выкл
- 🔊 кнопка рядом с сообщением для повтора

### 4.5 EddieServer (интеграция)

**Текущее состояние:** `core/eddie_server.py` — определён, но нигде не создаётся.

**Что нужно:**
- Chat App запускает EddieServer в фоновом потоке
- Сервер держит Agent + TCP обработку
- outbox.send() → server.send_initiative() → TCP broadcast

### 4.6 Фильтр инициативы

**Принцип (Эдди):** как живой человек — пишет когда есть
настоящий повод, не по расписанию и не по таймеру.
Частоту ограничивают сами условия, а не искусственные лимиты.

| Событие | Баллон | Почему |
|---------|--------|--------|
| Discovery: нашёл новую тему, хочу поделиться | ✅ | настоящий повод; редко сам по себе (новая тема = новая цель, пока активна — тишина) |
| Ask: хочу спросить направление | ✅ | редкие условия (≥6 целей, ≥3 завершённых) |
| Reflection: подвожу итог | ❌ файл | служебный статус |
| Goal completed | ❌ файл | служебный статус |

Если на живых прогонах окажется шумно — следующий шаг:
фильтр по аффекту/интересу (реальное «хочу сказать»),
не по времени.
