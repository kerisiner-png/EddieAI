# EddieAI Chat

Окно общения Эдди ↔ EddieAI: трей + уведомления + текст/голос.

## Запуск

Чат поднимается вместе с сессией EddieAI автоматически:

```
python night_run.py --minutes 30
python night_run.py --minutes 30 --no-chat   # без чата
```

Отдельно (свой экземпляр агента, для отладки):

```
python communication\chat_app.py
```

## Как это работает

- Иконка в трее. Левый клик — показать/скрыть окно,
  правый — меню («Открыть чат», «Выход»).
- EddieAI сам пишет первым: сообщение приходит как
  balloon-уведомление; клик по нему открывает чат.
- Ты пишешь в поле ввода (Enter — отправить) или через
  микрофон (кнопка 🎤, Vosk распознаёт русский).
- Ответ EddieAI озвучивается, если включён режим «Голос».
- Оба имеют право молчать: никто никого не тащит в чат.

## Файлы

| Файл | Роль |
|------|------|
| chat_app.py | Точка входа, связка компонентов |
| tcp_client.py | TCP-клиент к EddieServer (port 7778) |
| ui_chat.py | Окно чата (tkinter) |
| tray.py | Иконка трея + balloon (pystray) |
| voice_io.py | Голос: Vosk STT + edge-tts TTS |
