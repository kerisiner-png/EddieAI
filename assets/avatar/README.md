# Аватар EddieAI — рабочая папка артов

Создана 24.08.2026 (~19:26) по решению Эдди. Весь арт рисует Эдди
вручную (графпланшет). Решение обратимо: конвейер принимает любые PNG.
Папка входит в общий анализ состояния проекта (PROJECT_STATE.md).

## Структура

```
refs\      — референсы: любые картинки, вдохновение, нейро-рефы
designs\   — варианты дизайна до финализации (эскизы, черновики)
sprites\   — ТОЛЬКО финальные спрайты, подключаемые рантаймом
  base\    — дневной базовый дизайн
    body\    позы: idle, listening, talking, thinking, sleeping
    face\    эмоции: neutral, joy, fear, sad, interest
    mouth\   фазы: closed, parted, half, open, wide, narrow
    eyes\    open, closed
  designs\night\  ночной дизайн (тело+голова; лицо/рот/глаза общие)
  designs\work\   рабочий дизайн (собранные волосы, очки)
```

## Правила спрайтов (критично)

1. PNG 256×256, прозрачный фон.
2. Все слои одного холста; персонаж НЕ прыгает между кадрами
   одной анимации — экспорт по фиксированной сетке.
3. Имена файлов: латиница, нижний регистр, схема
   `<категория>_<имя>_<номер>.png`, например `body_idle_01.png`,
   `mouth_open.png`, `face_joy.png`.
4. Покадровые циклы: 4–8 кадров на цикл достаточно (idle),
   6–10 кадров для эмоциональных вспышек.
5. Рот и лицо — статичные слои (липсинк переключает их кодом,
   видео/анимация для них не нужна).
6. manifest.json генерирует инженер (opencode) по факту файлов —
   Эдди только кладёт PNG в нужные папки.

## График сдачи (решено 25.08 ночь)

- Фаза 0 (~недели 1–2): ~8 файлов минимального набора
  (body idle 2 кадра, eyes 2, mouth 4, face neutral) → первый запуск.
- Фаза 1 (~недели 3–4): полный дневной комплект ~25–35 файлов.
- Фаза 2 (без срока): дизайны night/work (~12–18 файлов каждый),
  доп. варианты эмоций ×3, длинные циклы.
